# Aisle Stack — first 10 short-form video scripts

Format for all: screen recording of an AI assistant window, prompt pasted in, output generated on screen (speed up the generation in editing if needed), text-on-screen captions, optional TTS voiceover. 30-45 seconds each. No face required.

General rule: the hook is the first 1.5 seconds — if it doesn't stop the scroll by then, the rest of the script doesn't matter.

---

Hook (on screen + voiceover): "If you plan weddings and you're still writing proposals from scratch, watch this."
Screen: paste Prompt #2 (full service proposal), fill brackets on screen, generate.
Voiceover while it generates: "This is a full proposal, sections and all, in about 40 seconds. You still edit it, but you're never starting from a blank page again."
End card: "Full prompt pack — link in bio."
