# Aisle Stack — 14-day launch calendar

Post to TikTok, Instagram Reels and YouTube Shorts simultaneously (same file, three uploads) unless a platform's performance clearly diverges after week 1. One post per day, same time of day, to give the algorithm a consistent signal.

| Day | Video | Notes |
|---|---|---|
| 1 | Script 1 — Proposal | Launch day. Pin this video, add link in bio before posting. |
| 2 | Script 2 — Vendor negotiation | |
| 3 | Script 3 — Day-of timeline | Usually the strongest hook of the first batch — watch its numbers closely. |
| 4 | Script 4 — Complaint response | Highest emotional stakes hook, often the best performer in this genre. |
| 5 | Repost best performer from days 1-4 to a second platform if it hasn't been posted there | Only if one video is clearly outperforming — do not repost a flat one. |
| 6 | Script 5 — Onboarding sequence | |
| 7 | Script 6 — Social captions | |
| 8 | Review days 1-7 numbers before posting | If nothing has more than a few hundred views, change the hook style before day 9, not the product. |
| 9 | Script 7 — Referral email | |
| 10 | Script 8 — Budget breakdown | |
| 11 | Script 9 — Thank-you email | |
| 12 | Script 10 — Compilation | Strongest CTA video; good candidate to boost/pin if any paid promotion is added later. |
| 13 | Re-record the best-performing hook with a different opening line (same content) | Tests whether the hook or the content drove performance. |
| 14 | Review 14-day numbers: views, follows, link clicks, sales | Decide whether to keep the current format, change the hook style, or change the platform mix. |

**Decision point at day 14:** if there are real views (thousands, not dozens) but no sales, the problem is the offer or the landing page, not the content — revisit the Gumroad listing. If there are no real views at all, the problem is the hook or the posting cadence, not the product.
