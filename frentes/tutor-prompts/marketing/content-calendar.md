# ClassStack — 14-day launch calendar

Same discipline as Aisle Stack: one post per day, same time of day, TikTok/Reels/Shorts simultaneously unless performance clearly diverges after week 1.

| Day | Video | Notes |
|---|---|---|
| 1 | Script 1 — Session recap | Launch day. Pin this video, add link in bio before posting. |
| 2 | Script 2 — Cancellation reminder | High-relatability hook, often a strong early performer. |
| 3 | Script 3 — Lesson plan generator | |
| 4 | Script 4 — Difficult conversation | Highest emotional stakes; watch this one's numbers closely. |
| 5 | Repost best performer from days 1-4 to a second platform if not already there | Only if one video is clearly outperforming. |
| 6 | Script 5 — Progress report | |
| 7 | Script 6 — New inquiry response | |
| 8 | Review days 1-7 numbers before posting | If nothing has real traction, change the hook style before day 9. |
| 9 | Script 7 — Referral request | |
| 10 | Script 8 — Homework with parent instructions | |
| 11 | Script 9 — Social captions | |
| 12 | Script 10 — Compilation | Strongest CTA video. |
| 13 | Re-record best-performing hook with a different opening line | Tests hook vs. content. |
| 14 | Review 14-day numbers: views, follows, link clicks, sales | Decide whether to keep format, change hook style, or change platform mix. |

**Decision point at day 14:** same as Aisle Stack — real views with no sales points to the offer or page; no real views points to the hook or cadence, not the product.
